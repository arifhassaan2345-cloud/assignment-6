# FitLog

FitLog is a workout tracking and planning web application built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Browse workout library
- View detailed workout information
- Add workouts to today's plan
- Save workouts for later
- Mark workouts as completed
- Remove individual workouts
- Remove all workouts from the plan
- Track total exercises, minutes, and calories
- Sort workouts by duration, calories, and rating
- Toast notifications
- Responsive design for desktop and mobile
- Workout not-found page
- Loading state

## Technologies

- Next.js
- TypeScript
- React
- Tailwind CSS
- REST API
- LocalStorage
